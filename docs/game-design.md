# もこもん ゲーム設計書

プロトタイプ(`prototype/mokomon.html`)で実証済みの仕様。**現在は Flutter 版(`app/`)とこのドキュメントが正**。プロトタイプは検証時点の凍結資料であり、以後の変更(種族8-9、進化ビジュアル強化など)は反映しない。

## 1. コンセプト

- ターゲット: 6〜7歳(+親)。文字はすべてひらがな・カタカナ
- コアループ: **ミニゲームでコインを稼ぐ → ごはんで育てる → 劇的に進化 → ずかんが埋まる → 新しいたまご**
- セッション設計: 1回5〜10分。お腹/ごきげんの時間減衰で「また開く理由」を作る

**しゃべり声(バブル音声)**: なでなで・ごはん後・ゲームから帰宅時などに、種族ごとの高さの「しゃべり風」合成音声(5〜8音節・3バリエーション)を再生する。どうぶつの森式の意味のないおしゃべり。声の高さは**全種族で別々**にする(`babbleBaseFreq`)。さらに**種族ごとに声の性格**を持つ(`_voiceStyles`。こどもFB「キャラで音を変えて」): かわいい系=サイン波のペンタトニック風、べろ=のこぎり波の濁り声、ぶう=低いブヒブヒ、めだま=音程が飛ぶ不思議声、ダンディ=低くしぶい、ぐる=ぐるぐる回る音程、ぱく=あむあむ短音、ねむ=下がっていくふにゃ声、ろぼ=ピコピコ機械声、おばけ=ゆらゆら声。該当のない種族・将来の追加種族はかわいい系が既定。種族を追加したときに既存の種族と同じ声にならないよう、`polish_test.dart` が衝突を検知する。
**ひとりごと**: 放置中、20〜32秒ごとに勝手にしゃべる(セリフ8種+バブル声+もじもじ)。たまご中は「たまごが ゆれた…!?」と揺れる。

**誇張表情(リアクション中だけ顔が差し替わる・全種族共通)**: なでなで/褒め=にっこり(∩∩目+大口+舌)、💨=びっくり(まん丸目+高眉+「お」の口)、ごはん=あーん(とじ目+大きく開けた口)。約1〜1.6秒で種族の顔に戻る。
**セリフの吹き出し**: 大きな文字(26px相当・自動縮小)+ぽよんと弾む登場+毎回わずかに傾く。

- しきい値: stage1→2 は xp **45**、stage2→3 は xp **120**、stage3→キング(4)は xp **240**(こどもFB「進化が早すぎる」「もう1段階ほしい」で拡張)

3. 白フラッシュ(0.9秒)

5. 「すごい!!」ボタンで閉じる

### 新しいたまごの抽選ルール
1. 金のたまご: 未入手 かつ 通常種のキングが3体以上 → **必ず種族3**(最優先)
2. それ以外: 未入手の通常種からランダム。ただし**いま育てている子と名簿で続きを待っている子の種族は引かない**

## 5. ミニゲーム(16種)

共通報酬: クリアで happy+12、xp+10(+ゲーム固有コイン)

**ゲームオーバー(こどもFBで追加)**: 正誤のあるゲーム(おなじのどれ?/ちがうのどっち?/じゅんばんタッチ/かぞえてタッチ/どっちがおおい?/けいさんタッチ/いろタッチ)は、
**3回まちがえるとゲームオーバー(報酬なし)**。「🪙5コインで つづける」を選べばミス回数がリセットされ、
続きから再挑戦できる(じゅんばんタッチはタイマーも一時停止)。コインが足りない・あきらめた場合は無報酬で終了。
反射系(フルーツキャッチ/もぐらたたき/ふうせんわり/なぞってかこう/ぴかっとタッチ/ぴったりストップ)と記憶系(ペアさがし/おぼえてタッチ/さかさまタッチ)は対象外
(誤タップ・不一致がゲームの一部、サイモン系は既に1ミスで終了する設計、ぴったりストップははずれが0コインでラウンド消化のため)。

### フルーツキャッチ(反射)
30秒。0.45〜0.85秒間隔で落下物(🍎🍊🍇🍓🍌、14%で⭐)。落下速度120〜220px/s+横揺れ。
**残り時間が減るほど加速**(出現間隔・落下速度とも最大1.9倍。こどもFBで難化)。
タップ判定半径44px。フルーツ+1コイン、⭐+3コイン。開始前に3,2,1カウントダウン。

### おなじのどれ?(パズル)
8ラウンド。形(丸/星/三角/四角/ハート)×色(5色)のターゲットと同じものを4択から(こどもFBで難化)。
不正解はシェイク演出+ミス+1(上記のとおり3ミスでゲームオーバー)。正解+2コイン、進捗ドット表示。

### ペアさがし(記憶)
4×5=20枚(10ペア: 🍎🍌🍇⭐🐟🌸🍩🐸🚗🌙)。カードフリップは3D回転0.35秒。
不一致は0.75秒後に伏せる。全ペアで+20コイン。(2人プレイでちょうどよい難易度に増量。こどもFB)

### もぐらたたき(反射・Flutter版で追加)
30秒。3×3の穴からいきもの(実際の種族絵)が0.75〜1.2秒だけ顔を出す。最大3匹同時。
ふつう+1コイン、きんいろ(ぴか)12%で+3、💨もぐら10%は0コイン(おふざけ)。終盤ほど加速(×1.8)。

### なぞってかこう(おえかき系・Flutter版で追加)
点線の形(ほし/はーと/まる/つき/かみなり)から3つをなぞる。輪郭カバー率で
★3(85%+, +4コイン)/★2(55%+, +3)/★1(+1)。おえかき好きのこども向け。

### ちがうのどっち?(観察・Flutter版で追加)
にている絵文字ペア(🍎🍅・😀😃・😺😸・🌕🌝等13組)のうち1つだけ違うものを探す。
8ラウンド、グリッドは12→16→20→25枚と拡大(こどもFBでさらに難化)。正解+2コイン。

### ふうせんわり(反射・Flutter版で追加)
30秒。下からふわふわ上がる🎈をタップ(+1)。⭐14%は+3、💣14%はさわると-2(0未満なし)。終盤加速(×1.8)。

### じゅんばんタッチ(かず・Flutter版で追加)
1〜9のボタンを順番にはやくタッチ。タイムでコイン(11秒未満+16 / 20秒未満+10 / それ以上+6)。

### かぞえてタッチ(かず・こどもFBで追加)
ちらばった絵文字(にたものが2種まざる)から対象をかぞえて3択で答える。
6ラウンド、9→24枚と増加。まちがいはミス+1(数えなおし可、3ミスでゲームオーバー)。正解+3コイン。

### おぼえてタッチ(記憶・こどもFBで追加)
4色パッドが光ったじゅんばんを覚えて同じ順にタッチ(サイモン)。2連から始まり
クリアごとに+1、最大7連。1ラウンド+3コイン、まちがえたらそこで終了(獲得分は持ち帰り)。

### どっちがおおい?(かず・こどもFBで追加)
左右にちらばった同じ絵文字のむれを見くらべて、多いほうをタッチ。6ラウンド。
差は 3個 → 2個 → 1個 と縮んで難化。正解+3コイン、ミス制(3ミスでゲームオーバー)対象。

### ぴかっとタッチ(はんしゃ・こどもFBで追加)
ランプが「ぴかっ」と光った瞬間にすばやくタッチ。5ラウンド。光るまでの待ちは0.9〜2.6秒でランダム。
はやさでコイン(0.4秒未満+3 / 0.8秒未満+2 / それ以降+1)。フライング(光る前タップ)はそのラウンド0コインで進む。

### けいさんタッチ(かず・高難度枠で追加)
たしざん・ひきざんの答えを3択から選ぶ。6ラウンドで難化:
たしざん(答え10まで)→ ひきざん(10までから引く)→ 11〜15のミックス(くり上がり・くり下がり相当)。
正解+3コイン、ミス制(3ミスでゲームオーバー)対象。

### さかさまタッチ(記憶・高難度枠で追加)
おぼえてタッチの逆順ルール: 光ったじゅんばんを**さかさまから**タッチ(SimonGame の reversed)。
逆順の記憶ははるかに難しいため2連から最大6連と短く、1ラウンド+4コイン(最大20)。
まちがえたらそこで終了(獲得分は持ち帰り)。

### ぴったりストップ(タイミング・高難度枠で追加)
バーを走るマーカーが「まと」の上に来た瞬間に「ストップ!」をタッチ。5ラウンドで
速さ0.55→1.35往復/秒と加速し、まとの半幅0.13→0.058と縮小。まと中心付近ぴったり+4 /
まと内+2 / はずれ0(ラウンドは進む)。まとの位置は毎ラウンドランダム。

### いろタッチ(しゅうちゅう・高難度枠で追加)
ストループ課題: 大きく出たことば(あか/あお/きいろ/みどり)の**文字の色**と同じ色パッドをタッチ。
最初の2問はことばと色が一致するならし、3問目からは必ず食い違う(ことばにだまされたらミス)。
6ラウンド、正解+3コイン、ミス制(3ミスでゲームオーバー)対象。

## 6. お絵かき(もようがえ)

- 体形のパス(**いまの子の種族×stageの形**)でクリップした透明レイヤーに描く。バケツの境界判定も同じ形を使う。ツールは**ふで(ふとさ3段階)/スタンプ/バケツぬりつぶし/けしごむ**

- 体の色も6色から変更可
- 保存した模様は体に合成表示。**体色とレイヤーを分離**(後から体色だけ変えられる)
- happy+8、xp+4
- 保存してホームに戻ると、いきものが褒めてくれる(スピン1回転+キラキラ6個+褒めセリフ4種からランダム。Flutter版で追加)

## 8. あいことばセーブ(パスワード方式)

- 形式: `MOKO-` + base64(`ver,stage,xp,coins,hunger,happy,species,collectionBits,ownedBits,equipHeadIdx,equipFaceIdx;checksum`)
- ver: 現行 **2**(5段階化)。ver 1 のコードも読める(stage 3=キングは 4 へ引き上げて復元)

## 14. キングのおみやげ(Flutter版で追加)

- キングは内部に**✨きらきらゲージ**(0-100)を持つ。**メーターは表示しない**(こどもFB「増えないゲージが気になる」。進化と同じサプライズ重視で、進捗は50%/85%の吹き出しだけで見せる)
- なでなで+2 / 💨+1 / ごはん+3 / ミニゲーム+6 / おえかき保存+5 で溜まる(なでなで50回・ミニゲーム約17回で満タン。こどもFB「すぐもらえすぎ」で2段階減速)
- 50%と85%で吹き出し(「きらきらが たまってきた…!」等)を出し、進捗の手ごたえを見せる
- 満タンで🎆おみやげ: 最初の3回は**限定スタンプ解放**(👑→🎆→🦄、+10コイン付き)、以降はコイン20〜40
- ゲージは個体ごと(名簿に保存)。スタンプ解放は端末共通。あいことばには含めない

  追加の8種(こどもFBで追加)は**コインで購入**: ふかいうみ🐋40 / ジャングル🐒30 / キャンディランド🍬40 / おしろ🏰**200** / オーロラ🌌**250** / おんせん♨️30 / よいちまつり🏮40 / はなばたけ🌷20(おしろ・オーロラは憧れ枠)
- **色はガラッと変える**(こどもFB): よぞら・うちゅうはほぼ真っ暗+星、ゆきはほぼ真っ白+雪、かざんは暗赤+火の粉。テーマ別の飾りも多め
- **種族ごとにデフォルト背景**(`data/backgrounds.dart` の speciesDefaultBg。例: おばけん→よぞら、ろぼっち→ゆき)は必ず無料テーマの中から選ぶ。種族追加時は必ず1エントリ足す

## 12. 名簿(roster)と交代・ニックネーム(Flutter版で追加)

- 名簿は**個体のリスト**(species 入りスナップショット)。だぶり卵は「おわかれ入れ替え」(§4)で起きなくなったため通常は1種族1匹だが、データとしては複数持てる(過去のセーブとの互換・上書き消失防止)
- 新しいたまごを迎えると(ベビー以降ならいつでも可)、いまの子は個体として**名簿**に追加される(species・stage・体色・模様・きせかえ・なまえ)
- **ずかんのセルをタップで交代**できる(入手済み・名簿の育成途中どちらも)。いま育てている子(たまご・育成途中でも)は名簿に退避され、続きから再開できる
- 同じ種族の個体が2匹以上いるセルは**×N バッジ**が付き、タップで「どの子と こうたい?」の個体選択が開く(1匹ならそのまま交代)。セルの代表は「いまの子>いちばん育っている個体」
- ずかん登録ずみだが名簿に個体がいない種族(旧セーブ・あいことば復元後)は、タップでキング姿の初期状態を迎える(adoptKing)
- 旧形式の名簿(種族ごとに1枠の Map)はセーブ読み込み時にリストへ自動移行する
- ずかんのセルは、いまの子と名簿の子は**すがた+なまえ**で表示(シルエット「???」は未知の種族のみ)
- きせかえの**装備状態は個体ごと**に保持(所持アイテム自体は共有)
- **ニックネーム**: 下部カードの名前ピルをタップ→10文字まで。個体ごとに保存。名簿・ニックネームは端末ローカルのみで、あいことばには含めない(復元時はリセット)
